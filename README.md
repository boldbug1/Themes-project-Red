# Themes-project-Red

a collection of themes made by community for project-red.


## Installation

1.**Download** your selected themes ```.css``` file.

2.Go to ```..\Project-RED\static```.

3.**Replace** the ```style.css``` file with new ```style.css```.
_(name of the ```.css``` file must be style.css)_

_Note : You can only use one theme at a time._
